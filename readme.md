Files for a customised version of the [Tiny-M](https://github.com/gsl12/Tiny-M) 3d printer.

- Controlled by Duet 2 Wifi
- Customised print head for e3d v6 hot end, including magnet mounted front fascia for mounting an IR sensor
- Upgraded from the original 150mm cantilevered bed to a 256mm square bed with triple Z lead screws (independent motor bed levelling via `M671`/`G32`)
- Extruder driven by an external driver on the expansion header, freeing the third onboard driver for the extra Z motor
